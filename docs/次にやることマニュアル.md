# 「生活リズム帳」リリース前後マニュアル(はじめての方向け)

このマニュアルは、専門知識がなくても、上から順番に読んで実行すれば
迷わないように作られています。

---

## ステップ0:まず知っておいてほしいこと

- このアプリは、AIによる自動テストを**非常に多くの角度から、何度も繰り返し**行っています。
- ただし、**実際のiPhone・Androidの実機だけは、AIが直接触って確認することができません。**
- そのため、リリース前に**人の手による最終確認が1回だけ必須**です。難しい作業ではありません。次のステップ1で、その方法を説明します。

---

## ステップ1:リリース前に必ずやること(実機の最終確認)

### 用意するもの
- お手持ちのiPhoneまたはAndroidスマートフォン
- 渡されたファイル `生活リズム帳_修正版(最新).html`

### やること(15分程度)

1. **ファイルをスマートフォンに送る**
   - LINE、メール、AirDrop、Googleドライブなど、どの方法でも構いません。
   - スマートフォンの中に `生活リズム帳_修正版(最新).html` が保存されればOKです。

2. **ブラウザで開く**
   - ファイルをタップして開く(または、ブラウザ(Safari・Chrome)を開いてから、そのファイルを選択)。
   - インターネット接続がなくても開けます。

3. **画面を上から下まで、一通り触ってみる**
   以下を実際にやってみて、違和感がないか確認してください。
   - [ ] 起床・就寝の時刻を入力してみる
   - [ ] 朝食の内容を入力し、「栄養を計算」を押してみる
   - [ ] 「ラジオ体操」などのマスをタップしてみる(スタンプが押されるか)
   - [ ] やることリストに何か1つ追加してみる
   - [ ] 右上の歯車アイコンから設定画面を開き、文字サイズを「特大」にしてみる
     → 文字が画面からはみ出したり、切れたりしていないか確認
   - [ ] 写真のボタンから、実際に写真を1枚追加してみる
   - [ ] 「全データを書き出す」でバックアップファイルを作成してみる
   - [ ] 作成したバックアップファイルを「読み込む」で復元してみる
     → 入力した内容がちゃんと戻ってくるか確認

4. **違和感があれば、スクリーンショットを撮ってメモしておく**
   - 「ここの文字が切れている」「ここが押しにくい」など、気づいたことをメモ。
   - 気になる点があれば、開発担当(AI)に伝えれば、原因を調べて修正できます。

5. **問題がなければ、リリースして大丈夫です。**

## ステップ2:リリースの仕方(配布方法)

このアプリは特別な公開作業は不要です。以下のいずれかの方法で配布できます。

### 方法A:ファイルをそのまま配る(一番シンプル)
`生活リズム帳_修正版(最新).html` のファイルを、使ってほしい人に直接渡すだけです。
受け取った人は、ステップ1の2と同じ方法(タップして開く)で使い始められます。

### 方法B:ダウンロードページを作る
自分のWebサイトやGoogleドライブの共有リンクなどに、このファイルを置いておく方法です。
利用者はリンクからファイルをダウンロードして開きます。

**どちらの方法でも、サーバーの契約やアプリストアへの申請は不要です。**

## ステップ3:リリース後、日常的にやってほしいこと

### 3-1. バックアップの習慣化(最重要)

このアプリのデータは、**使っている端末の中だけ**に保存されています。
端末を機種変更したり、故障したりすると、バックアップを取っていない場合はデータが失われます。

**おすすめの頻度**:

| 頻度 | やること |
|---|---|
| 1年に1回以上 | アプリ内の「全データを書き出す」でバックアップファイルを作る |
| 5年に1回程度 | バックアップファイルを、今と違う保存場所(外付けHDD・別のクラウド等)にもコピーしておく |
| 機種変更の前 | 必ずバックアップを取ってから機種変更する |

バックアップファイルは、`家族への手紙_データの見方.md` を読めば、
専門知識がない人でも中身の見方・復元方法が分かるようになっています。

### 3-2. 定期的な軽い見直し(任意)

数年に1回程度、以下を確認すると安心です。
- 最新のiPhone/Androidでも問題なく開けるか(たまに新しいスマホで試してみる)
- バックアップファイルが、ちゃんと復元できる状態か確認する

---

## ステップ4:もし不具合・気になる点が見つかったら

1. **まず慌てず、データが消えていないか確認する**
   → データは全て自動保存されているため、通常は消えません。
2. **バックアップを取る**(念のため、今の状態を保存しておく)
3. **何が起きたかをメモする**(いつ・どの画面で・何をしたら・どうなったか)
4. 開発担当(AI)に、上記のメモとスクリーンショットを共有して、修正を依頼する
