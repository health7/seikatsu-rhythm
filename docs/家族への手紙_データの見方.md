# 「生活リズム帳」データの見方・復元方法(ご家族・将来のあなたへ)

このファイルは、「生活リズム帳」という生活記録アプリを使っていた方の
データを、ご家族や将来ご本人が見返す・引き継ぐ際の手引きです。

## このデータは何か

「生活リズム帳」は、日々の睡眠・食事・習慣・写真・やることなどを記録する、
スマートフォンやパソコンのブラウザで動く記録アプリです。

- **サーバーやクラウドには一切保存されません。** データは常に、使っていた
  端末(スマートフォン・パソコン)の中だけに保存されています。
- 特別な会員登録・サブスクリプション契約・企業アカウントは一切不要です。
- データを見る・引き継ぐために必要なのは、**このアプリ本体のファイル
  (`生活リズム帳_修正版(最新).html`)** と、**バックアップファイル
  (`.json`という拡張子のファイル)** の2つだけです。

## 見る方法(3ステップ)

1. `生活リズム帳_修正版(最新).html` というファイルを、パソコンやスマート
   フォンのWebブラウザ(Google Chrome、Safari、Microsoft Edge など、
   一般的などのブラウザでも構いません)にドラッグ&ドロップするか、
   ダブルクリックして開いてください。インターネット接続は不要です。
2. アプリが開いたら、右上の歯車アイコン(設定)を押し、
   「バックアップファイルを読み込む」を選んでください。
3. お持ちのバックアップファイル(`.json`)を選択すると、確認画面が出ますので
   内容を確認して「読み込む」を押してください。記録内容がそのまま表示されます。

## 万一、アプリのファイルが手元にない場合

バックアップファイル(`.json`)は、実は**専用のアプリが無くても、
パソコンの「メモ帳」や「テキストエディット」等、文字を表示できる
どんなソフトで開いても中身を読むことができます。**

バックアップファイルを開くと、中に `formatGuide` という項目があり、
そこに「どの項目が何を意味するか」の説明が日本語の文章で書き込まれています
(例:「taisoという項目は、ご本人が設定した運動習慣を行ったかどうかです」等)。
これにより、アプリそのものが将来使えなくなった場合でも、記録の内容が
何を意味していたかが分かるようになっています。

写真は `photos` という項目の中に、一般的なJPEG画像を文字列に変換した形で
含まれています。この変換方式(Base64)は世界的に広く使われている標準的な
方式のため、「生活リズム帳」以外のプログラムでも元の画像に戻すことができます。

## よくある質問

**Q. パスワードや会員情報は必要ですか？**
いいえ、一切不要です。ファイルさえあれば誰でも開けます。

**Q. 開くと個人情報が誰かに送信されませんか？**
いいえ、送信されません。全ての処理はお使いの端末の中だけで完結します。

**Q. データを直接誰かに見せたくない場合は？**
バックアップファイルを渡さなければ、他の誰にも見られることはありません。
このアプリ・データは、渡した相手の手元だけで完結する仕組みです。

## 長期保管のおすすめ

- バックアップファイル(`.json`)は、USBメモリ・外付けハードディスク・
  クラウドストレージなど、複数の場所に分けて保管することをおすすめします。
- できれば1年に1回程度、最新のバックアップを取り直してください
  (アプリ内の「全データを書き出す」ボタンから、いつでも作成できます)。
- 5年・10年など節目のタイミングで、新しい保存媒体へコピーし直すと、
  記録媒体自体の劣化・世代交代にも安心です。
